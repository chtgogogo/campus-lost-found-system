**原状**：`config.py` 默认 `dev-secret-change-me-in-production`，compose 未注入，任何漏配环境都带弱密钥上线。

**修复**：
- `app/core/config.py`：`JWT_SECRET` 默认改空串；新增 `validate_security_config()`（fail fast：空值 / `dev-` 前缀 / 占位符一律 `RuntimeError` 拒绝启动），在 `create_app()` 最先调用；
- 本机 `.env`：`secrets.token_hex(32)` 生成 64 位 hex 新密钥（旧弱默认作废）；
- `.env.example`：仅占位 `change-me-to-a-random-64hex`；
- `docker-compose.yml`：backend 增加 `JWT_SECRET: ${JWT_SECRET:?请在 .env 设置 JWT_SECRET}`。
