## 三、发布失物流程（核心）

```
用户点击"发布失物"按钮
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  前端: views/PublishView.vue                                 │
│  1. 上传图片                                                  │
│  2. watch 监听 foundFiles → 调用 visionApi.predict            │
│  3. 自动预填类目下拉框                                        │
│  4. 填写标题、描述、外观、特征、地点                          │
│  5. 点击发布 → POST /api/v1/items/lost                       │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  后端: routers/items.py                                      │
│  @router.post("/lost")                                        │
│  1. Depends(get_current_user) → 验证 JWT                     │
│  2. Depends(get_db) → 获取数据库会话                          │
│  3. 调用 PublishService(db).publish_lost(user, dto)          │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  后端: services/publish_service.py                           │
│  def publish_lost(publisher, dto):                           │
│                                                              │
│  Step 1: 图片存储                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ storage_util.save_images(dto.images)                    │ │
│  │ → 保存到 uploads/ 目录，返回 URL 列表                   │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 2: 视觉识别                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ vision_result = get_vision_service().predict(first_bytes)│ │
│  │ → 返回 {category_id, label, confidence}                 │ │
│  │ → 永不抛异常，失败返回"其他"类 + confidence=0.0         │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 3: 标签抽取                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ tags = TaggingService.extract(                         │ │
│  │     title=dto.title,                                   │ │
│  │     description=dto.description,                       │ │
│  │     vision_label=self._vision_label(vision_result),    │ │
│  │     category_name=dto.category_name.strip(),           │ │
│  │ )                                                       │ │
│  │ → 返回 ["钥匙", "银色"]                                │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 4: 类目解析                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ category_id = self._resolve_category_id(               │ │
│  │     dto.category_name.strip(),                         │ │
│  │     vision_result,                                     │ │
│  │     tags                                               │ │
│  │ )                                                       │ │
│  │ 优先级: 用户填写 > 名词 tag > 视觉识别                 │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 5: 计算感知哈希                                        │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ image_hash = PerceptualHash.compute(first_bytes)       │ │
│  │ → 返回 "a1b2c3d4e5f6g7h8" (16位十六进制)              │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 6: 入库                                                │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ lost = LostItem(                                       │ │
│  │     publisher_id=publisher.id,                         │ │
│  │     category_id=category_id,                           │ │
│  │     title=dto.title,                                   │ │
│  │     description=dto.description,                       │ │
│  │     images=image_urls,                                 │ │
│  │     tags=tags,                                         │ │
│  │     image_hash=image_hash,                             │ │
│  │     status=0,  # 待匹配                               │ │
│  │ )                                                       │ │
│  │ db.add(lost)                                           │ │
│  │ db.flush()                                             │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 7: 写审计日志                                          │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ audit_service.write_audit(                             │ │
│  │     db,                                                │ │
│  │     user_id=publisher.id,                              │ │
│  │     action="publish_lost",                             │ │
│  │     target_type="lost",                                │ │
│  │     target_id=lost.id,                                 │ │
│  │ )                                                       │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 8: 反向主动匹配（核心亮点）                           │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ matches = self._reverse_match_lost(lost)               │ │
│  │                                                         │ │
│  │ 8.1 候选召回                                            │ │
│  │ ┌────────────────────────────────────────────────────┐ │ │
│  │ │ candidates = self._recall_lost_candidates(lost)    │ │ │
│  │ │ → 只召回「同类目 ∪ 共享物品名词」的拾物            │ │ │
│  │ └────────────────────────────────────────────────────┘ │ │
│  │                                                         │ │
│  │ 8.2 打分                                                │ │
│  │ ┌────────────────────────────────────────────────────┐ │ │
│  │ │ for f in candidates:                                │ │ │
│  │ │     score = self._matcher.score(lost, f)           │ │ │
│  │ │     scored.append((score, f))                      │ │ │
│  │ └────────────────────────────────────────────────────┘ │ │
│  │                                                         │ │
│  │ 8.3 排序                                                │ │
│  │ ┌────────────────────────────────────────────────────┐ │ │
│  │ │ scored.sort(key=lambda pair: (-pair[0], pair[1].id))│ │ │
│  │ │ → 按分数降序，同分按 id 升序（确定性）             │ │ │
│  │ └────────────────────────────────────────────────────┘ │ │
│  │                                                         │ │
│  │ 8.4 切片                                                │ │
│  │ ┌────────────────────────────────────────────────────┐ │ │
│  │ │ for score, f in _cut_with_suspects(scored, MATCH_TOP_N):│
│  │ │ → 保底前 10 条 + 所有 ≥80 分的疑似                │ │ │
│  │ └────────────────────────────────────────────────────┘ │ │
│  │                                                         │ │
│  │ 8.5 入库                                                │ │
│  │ ┌────────────────────────────────────────────────────┐ │ │
│  │ │ m = MatchRecord(                                    │ │ │
│  │ │     lost_id=lost.id,                               │ │ │
│  │ │     found_id=f.id,                                 │ │ │
│  │ │     match_score=score,                             │ │ │
│  │ │     status=0,  # 待认领                           │ │ │
│  │ │ )                                                   │ │ │
│  │ │ db.add(m)                                          │ │ │
│  │ └────────────────────────────────────────────────────┘ │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 9: 提交事务                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ db.commit()                                            │ │
│  │ → 一次性提交所有变更（失物 + 匹配记录 + 审计日志）    │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  返回: (lost, matches)                                       │
└─────────────────────────────────────────────────────────────┘
```

## 四、七维打分流程

```
MatchService.score(lost, found)
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 特征抽取                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ lost_f = self.extract_features(lost, is_lost=True)     │ │
│  │ found_f = self.extract_features(found, is_lost=False)  │ │
│  │                                                         │ │
│  │ 抽取顺序（不可调换）：                                 │ │
│  │ 1. extract_place(text) → 地点                          │ │
│  │ 2. extract_color_words(rest) → 颜色                    │ │
│  │ 3. extract_qty(rest) → 数量                            │ │
│  │ 4. extract_states(rest) → 状态                         │ │
│  │ 5. _residual_keywords(rest) → 关键词                   │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 2: 七维打分                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ photo_category = _score_photo_category(                │ │
│  │     lost_f, found_f)                                    │ │
│  │ → 同类目=20, 近似=10, 不同=0, 缺失=10                 │ │
│  │                                                         │ │
│  │ qty = qty_score(lost_f.qty, found_f.qty)               │ │
│  │ → 五档: 15/12/10/7/0                                   │ │
│  │                                                         │ │
│  │ color = color_score(lost_f.colors, found_f.colors)     │ │
│  │ → 颜色家族归一化后判断，冲突时软化                     │ │
│  │                                                         │ │
│  │ state = state_score(lost_f.states, found_f.states)     │ │
│  │ → 状态词命中率                                          │ │
│  │                                                         │ │
│  │ place = place_score(lost_f.place, found_f.place)       │ │
│  │ → 相同/包含=1.0, 编辑距离≥0.6计分                     │ │
│  │                                                         │ │
│  │ keyword = _score_keyword(lost_f, found_f)              │ │
│  │ → 残余 token 命中率（含语义匹配）                      │ │
│  │                                                         │ │
│  │ time = _score_time(lost, found)                        │ │
│  │ → exp(-Δd/15), τ=15天                                  │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 3: 计算原始分                                          │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ raw_total = photo_category + qty + color + state       │ │
│  │            + place + keyword + time                    │ │
│  │ → 合计 100 分                                          │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 4: 归一化                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ provided = {                                           │ │
│  │     "photo_category": lost_f.has_category,            │ │
│  │     "qty": lost_f.has_qty,                             │ │
│  │     "color": lost_f.has_color,                         │ │
│  │     "state": lost_f.has_state,                         │ │
│  │     "place": lost_f.has_place,                         │ │
│  │     "keyword": lost_f.has_keyword,                     │ │
│  │     "time": time_provided,                             │ │
│  │ }                                                       │ │
│  │                                                         │ │
│  │ W_provided = Σ(该维度满分 if provided else 0)          │ │
│  │ → 只由失主侧决定（候选侧永不进分母）                  │ │
│  │                                                         │ │
│  │ k = 100 / max(W_provided, 50)                          │ │
│  │ → 50 是防爆下限                                        │ │
│  │                                                         │ │
│  │ total = clamp(raw_total * k, 0, 100)                   │ │
│  │ → 归一化后的最终分数                                   │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 5: 返回结果                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ return {                                               │ │
│  │     "total": total,                                    │ │
│  │     "dims": dims,                                      │ │
│  │     "provided": provided,                              │ │
│  │     "signals": signals,                                │ │
│  │     "keyword_hits": keyword_hits,                      │ │
│  │     "raw_total": raw_total,                            │ │
│  │     "norm_factor": k,                                  │ │
│  │ }                                                       │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

## 五、语义匹配流程

```
_token_hit(token, candidate_tokens)
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 精确匹配                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ if token in candidate_tokens:                          │ │
│  │     return True                                        │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 2: WordNet 英文同义词（nltk 缺失则跳过）              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ if USE_WORDNET:                                         │ │
│  │     for syn in _wordnet_synonyms(token):               │ │
│  │         if syn in candidate_tokens:                    │ │
│  │             return True                                │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 3: 中文近义词表（nltk 缺失则跳过）                    │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ if USE_WORDNET:                                         │ │
│  │     for syn in _zh_synonyms(token):                    │ │
│  │         if syn in candidate_tokens:                    │ │
│  │             return True                                │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 4: 未命中                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ return False                                           │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘

示例：
- token="钥匙", candidate_tokens={"钥匙串"}
- Step 1: "钥匙" in {"钥匙串"} → False
- Step 2: USE_WORDNET=True, _wordnet_synonyms("钥匙") → {} (英文无)
- Step 3: _zh_synonyms("钥匙") → {"钥匙扣", "钥匙串", "钥匙链"}
- "钥匙串" in {"钥匙扣", "钥匙串", "钥匙链"} → True
- 返回 True（命中）
```

## 六、视觉识别流程

```
VisionService.predict(image_bytes)
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 检查模型可用性                                      │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ if self._coco_model is None and self._world_model is None:│
│  │     return self._fallback()  # 直接降级                │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 2: 图片解码                                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ try:                                                    │ │
│  │     img = self._decode_image(image_bytes)              │ │
│  │ except Exception:                                       │ │
│  │     return self._fallback()  # 解码失败降级            │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 3: 双分支推理                                          │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ coco = self._predict_coco(img)                          │ │
│  │ world = self._predict_world(img)                        │ │
│  │                                                         │ │
│  │ # 合并择优：取白名单内置信度最高的类                    │ │
│  │ for cand in (coco, world):                              │ │
│  │     if cand is None:                                    │ │
│  │         continue                                       │ │
│  │     if best is None or cand[2] > best[2]:              │ │
│  │         best = cand                                    │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Step 4: 返回结果或降级                                      │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ if best is None:                                        │ │
│  │     return self._fallback()  # 无检测结果降级          │ │
│  │                                                         │ │
│  │ return {                                                │ │
│  │     "category_id": best[0],                            │ │
│  │     "label": best[1],                                  │ │
│  │     "confidence": round(float(best[2]), 4),            │ │
│  │ }                                                       │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  降级函数 _fallback()：                                     │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ cat = next((c for c in self._active if c[1] == "其他"), None)│
│  │ return {"category_id": cat[0], "label": "其他", "confidence": 0.0}│
│  │ → 永不抛异常，返回有效活跃分类                         │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

## 七、交接码流程

```
用户点击"生成交接码"
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  后端: handover_service.py                                  │
│  def generate_code(match_id, user_role):                    │
│  1. 生成 6 位动态码                                          │
│     code = ''.join(random.choices('ABCDEFGHJKLMNPQRSTUVWXYZ23456789', k=6))│
│     → 避开 0/O/1/I 等易混字符                               │
│  2. 生成 QR token                                            │
│  3. 设置 30 分钟 TTL                                         │
│  4. 返回 HandoverCode                                        │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  前端: views/HandoverView.vue                               │
│  1. 显示二维码 + 码值                                        │
│  2. 等待双方扫码/输码                                        │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────┐
│  后端: handover_service.py                                  │
│  def verify(match_id, user_role, code, gps):                │
│  1. 查询 HandoverCode                                        │
│     → 检查是否过期                                           │
│  2. 验证码值                                                  │
│     → if code != handover.code: raise HandoverInvalidError  │
│  3. 更新验证状态                                              │
│     → if user_role == "lost": handover.verified_by_lost = True│
│     → if user_role == "finder": handover.verified_by_finder = True│
│  4. 双方都验证通过 + GPS 一致 → 交接完成                    │
│     → complete_handover(match_id)                           │
│     → lost.status = 3 (已解决)                              │
│     → found.status = 1 (已解决)                             │
└─────────────────────────────────────────────────────────────┘
```

```

                              ▼

│       │            │              │              │          │

                              │
                              │ HTTP /api/v1/*
                              ▼
```

## 九、面试时如何使用这些流程图

### 被问"发布失物的流程"时：
> "用户上传图片后，后端先调用视觉识别，再抽取标签，然后解析类目，计算感知哈希，入库，写审计日志，最后反向匹配候选。具体流程可以看 publish_service.py 的 publish_lost 函数。"

### 被问"匹配算法怎么工作"时：
> "先抽取特征（按顺序：地点→颜色→数量→状态→关键词），然后七维打分（照片20+数量15+颜色20+状态10+地点15+关键词10+时间10），最后归一化（k=100/max(W_provided,50)）。代码在 match_service.py 的 score 函数。"

### 被问"怎么防冒领"时：
> "生成 6 位动态码，30 分钟有效，避开易混字符。双方都必须验证对方的码，加上 GPS 核验，必须线下当面才能完成交接。代码在 handover_service.py。"
