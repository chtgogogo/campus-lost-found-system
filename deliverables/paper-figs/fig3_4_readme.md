## 相对原图（位图版 图3.4）所做的修改

1. **删除"游客"参与者（actor）**
   原位图里包含 4 个 actor：失主 / 拾得者 / 管理员 / **游客**。
   与正文已统一结论（**三类角色：失主/拾得者/管理员**，未登录用户不视为角色）不一致，故删除"游客"actor。
   本图参与者恒为 **3 个**（失主 / 拾得者 / 管理员）。

2. **原属游客的"浏览公示栏"用例降级为公开用例**
   - 在用例椭圆上以虚线 + 暖色填充（橙 #C55A11）显著标识；
   - 上方标注 `«公开用例»` 与 `未登录用户可访问，无需登录`；
   - **不连任何 actor**（UML 语义：公开用例可被任意访问者触发，不需要识别为参与者）。

3. **用例名严格取自论文正文 para#123**
   提取自正文实际列出的用例，无自行编造：
   - 失主：发布失物 / 查看匹配 / 认领 / 验证交接码 / IM 沟通
   - 拾得者：发布拾物 / 确认归还 / 生成交接码 / IM 沟通
   - 管理员：审计时间线 / 封禁 / 分类管理
   - 未登录用户（公开）：浏览公示栏

4. **复用 "IM 沟通" 用例**
   失主与拾得者都关联到 "IM 沟通" 椭圆（用关联线分别连接，避免重复画椭圆）。

## 在 Word 中替换原图 3.4 的步骤

1. 在 Word 中打开 `曹灏天计算机学院毕业论文-2026版（7-6）.docx`。
2. 定位到章节"**系统功能分析**"→"**UML的用例图如图3.4所示**"（para#165 / 段落标题附近，原图位于 para#167 标题"图 3.4 用例图"下方）。
3. **右键 → 删除** 原图 3.4 的位图对象（若与图 3.10 重复使用，需同时确认 para#314 注记可在定稿前删去该说明）。
4. **插入 → 图片** → 选择 `fig3_4_usecase.svg`（推荐，矢量清晰）或 `fig3_4_usecase.png`。
5. 调整图片宽度至与正文版心一致（建议 14~15 cm），保持居中。
6. 确认图下方的图题"图 3.4 系统用例图"保留（para#125 / para#167 之一），文字未改。
