## 六、诚实暴露的弱点（最差 3 项）

1. **dev.db 无备份机制**（P2）：本次会话曾因压测脚本误清 dev.db（已重建演示库 + 加 loadtest 硬护栏）。修法：启动时自动 backup 或定时复制。
2. **评测集乐观偏差**（P2，已知已知）：主集参与调参，盲集 12 对 F1 57.1% 已量化差距；扩盲集至 50 对在 backlog。
3. **torch 2.7.1 Windows 多线程 load 偶发段错误**（P2）：v17④ 已架构性消除触发面（CLIP/YOLO 收敛单线程 worker），记录为已知原生库风险，重装 CPU 版 torch 可彻底规避。
